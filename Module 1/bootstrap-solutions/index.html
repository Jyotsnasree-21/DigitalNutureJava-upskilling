Exercise 19 — Customisation with Sass

Sass setup requires npm — steps shown below with sample code

Exercise 19.1 — npm Setup
npm init -y
npm install bootstrap@5.3.3
npm install --save-dev sass

Then create src/custom.scss and compile with: 

npx sass src/custom.scss dist/custom.css
Exercise 19.2 — _variables.scss
// custom.scss

// Override primary color
$primary: #1a3c5e;

// Override border radius
$border-radius: 10px;
$border-radius-pill: 50rem;

// Override font
$font-family-base: 'Poppins', sans-serif;

// Import Bootstrap AFTER overrides
@import "../node_modules/bootstrap/scss/bootstrap";

After compiling, link dist/custom.css instead of the CDN link.
